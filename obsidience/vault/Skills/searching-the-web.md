---
title: Search web
kind: skill
tool: '[[Tools/web.search]]'
---
Use `web.search` to discover a small set of direct, relevant source candidates.
Prefer primary and official publishers, use specific queries, and inspect dates
and result URLs before selecting anything. A result snippet is only a lead: it
can be stale, incomplete, or misleading and must never be cited as evidence.

Call `web.fetch` on the chosen direct page. If search fails or returns no
suitable source, report that honestly rather than inventing a URL or claim.
