title: Obsidian Web Clipper source-capture model
---

Obsidian’s official Web Clipper captures web material into durable Markdown files that remain readable offline. Its template system can combine page variables, filters, note-name and path formats, properties, and content templates so a capture preserves source metadata and a bounded body in a repeatable shape.

For Executive this is a source-capture pattern, not a trust shortcut. A clipped title, author, date, URL, or page body remains source material. Alexandria must still preserve provenance, distinguish direct evidence from synthesis, reject unsafe or generic pages, and move accepted claims through the normal review and relationship rules.
