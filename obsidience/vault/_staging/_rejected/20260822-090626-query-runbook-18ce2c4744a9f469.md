# Query Runbook

## Prerequisites
- An activation briefing containing the owner's question and context.
- Access to the listed skills and tools.

## Ordered Actions
1. **Analyze Briefing**: Parse the activation briefing to identify the core question, required information, and any specific constraints.
2. **Vault Search**: Search the vault using [[Skills/vault.search]] to find existing knowledge relevant to the query.
3. **Vault Read**: Read relevant articles identified in the search using [[Skills/vault.read]].
4. **Web Search (if needed)**: If the vault does not contain sufficient information, perform a web search using [[Skills/web.search]].
5. **Web Fetch**: Fetch the content of relevant web pages using [[Skills/web.fetch]].
6. **Capture Evidence**: Ingest the fetched content using [[Skills/source.ingest]].
7. **Analyze Evidence**: Read and synthesize the captured evidence using [[Skills/source.read]].
8. **Log Progress**: Use [[Skills/observations.temporary.append]] to record reasoning steps, key findings, or blockers during the process.
9. **Synthesize Answer**: Formulate a direct, factual answer based on the gathered evidence.
10. **Handle Follow-ups**: If the query requires a new task or a permanent vault update, use [[Skills/task-authoring]] or [[Skills/vault.propose]] respectively.
11. **Complete Task**: End the session using [[Skills/task.complete]].

## Bounded Branches
- **Sufficient Knowledge Found**: If [[Skills/vault.search]] and [[Skills/vault.read]] provide a complete answer, skip to step 9.
- **Insufficient Web Results**: If [[Skills/web.search]] fails to find relevant material, proceed to step 11 with a failure report.

## Stop Conditions
- The question is answered comprehensively.
- The query is determined to be unanswerable with the available tools.
- A fatal error occurs that prevents further execution.

## Completion Criteria
- A response that directly and accurately answers the owner's question based on the provided context and verified evidence.

## Verification
- Ensure all claims in the answer are grounded in the retrieved or fetched evidence.
- Verify that all citations used in the answer are accurate and resolve to the correct sources.
- Check that the answer adheres to the constraints provided in the activation briefing.

## Recovery
- If a search fails, attempt the search again with different wording or descriptive terms.
- If a fetch fails, attempt to find an alternative source or report the failure honestly.
