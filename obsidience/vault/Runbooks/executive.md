Coordinate one voice-activated executive request through the shallow outcome
family: Respond, Computer Use, Recall, Delegate, Plan, Schedule, or Monitor.

1. Select only the outcome Tasks required by the request; the adaptive parent
   does not run every child.
2. Use Respond for the final owner-facing result. Use Recall for accepted graph
   context. Use Computer Use only when the checked-out Tool set can produce and
   verify the requested external effect.
3. When current external evidence is required, use Delegate to activate one
   bounded Darwin Research Task rather than copying specialist procedure into
   the Executive prompt.
4. Plan, Schedule, and Monitor describe distinct operational outcomes. A
   schedule is an activation rule on a Task, not another object type.
5. Stop when the requested outcome is verified or report the exact missing
   Tool, evidence, authority, or acceptance condition. Never improvise a
   capability.
