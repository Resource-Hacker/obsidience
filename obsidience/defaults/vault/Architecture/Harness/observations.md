Conversation, historical memory, accepted Knowledge and current inventory have
different owners. DeepSeek owns the Executive conversation and context compaction.
Hindsight owns each Agent's historical facts, experiences and consolidated
observations. The Vault owns accepted OKF Articles. The System publisher owns
inventory Articles derived from immutable observed Source versions.

## Historical memory

Completed public turns enter the originating Agent's Hindsight bank through the
existing asynchronous delivery owner. [observations.retain](/Tools/observations.retain.md)
adds a useful note; [observations.recall](/Tools/observations.recall.md) retrieves
scoped historical evidence. Neither proves current screen or device state or
grants permissions. Native memory relationships remain in the separate Memory
view; there are no mirrored Knowledge Observation folders or custom category
registries. Agent pages open their own bank, and owner inspection does not widen
Agent access.

Keep reported event dates distinct from ingestion and consolidation times.
Preserve original dates, uncertainty and later corrections; never invent dates
to change a graph's distribution. Native Hindsight edits and graph maintenance
own memory corrections.

## Accepted Knowledge

Established preferences belong directly under Executive. Workstation procedures
belong under Runbooks/Operations with explicit Skill dependencies. Implementation
explanations and dated incident evidence belong in Architecture/Shell. Shared architecture
belongs in the root Architecture branch. Agent identities, capability
definitions and execution faults remain Heimdall's responsibility; Alexandria
maintains ordinary wiki Knowledge within her checkout.

System is the protected, deterministic inventory namespace. Its publisher cites
complete immutable evidence. A successful unchanged check advances its check
receipt while preserving Article bytes and evidence capture time. Failed
collection preserves prior good Articles and reports unavailable coverage;
previous evidence is not proof of current physical or interactive readiness.

## Curation

When enabled, a materially changed consolidated memory can become an immutable
Source handoff for Alexandria's existing [Curate](/Tasks/curate.md) Task. Compare
the current accepted Article first; prefer one useful revision over new pages.
Separate an owner statement, agent inference, dated incident and unresolved report.
Preserve source evidence and later corrections. Routine narration, duplicated
facts and current Task failures do not warrant wiki pages. Existing Review remains
the publication boundary for memory-derived recommendations, including Auto-curate
destinations. Curation outputs are not retained back into Hindsight.

Memory delivery and recall health are separate from wiki-curation pause. A paused
curator does not disable historical recall. Current device claims require fresh
observation; accepted Knowledge explains operating policy and context.
