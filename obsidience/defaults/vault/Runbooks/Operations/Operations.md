Operations contains reusable workstation procedures. Start with
[Application launch and window management](/Runbooks/Operations/application-launch-and-window-management.md)
and select only the procedure matching the current requested outcome.

Each procedure declares exact Skills; each Skill resolves to its existing Tool.
The graph derives these dependency links from accepted metadata. This navigation
index does not execute its procedures together or grant capabilities.

Current inventory belongs to the installation-generated System branch.
Implementation and incident context belong to [Shell architecture](/Architecture/Shell/Shell.md).
Procedure and dependency changes use definition Review; ordinary historical
memory curation does not edit executable Skill bindings. A separately queueable
outcome needs its own explicit Task binding before execution.
