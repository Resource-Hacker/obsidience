## Runtime

Use observations.recall when an earlier preference, correction, commitment or reported outcome is needed. The Executive receives a small automatic recall at turn admission; call this Tool only if additional historical context is needed. Prefer current owner corrections and retain attribution and dates. A current screen or application question still requires a fresh computer.observe. Missing memory is not a reason to invent history. Durable Knowledge proposals remain Alexandria's responsibility through Curate and Review.
